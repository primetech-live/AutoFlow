# AutoFlow CLI 🚀

AutoFlow is a powerful, automated CI/CD Command Line Interface (CLI) tool designed specifically for students and beginners. It simplifies the deployment process by bridging your local development environment directly to a remote server using Git and Docker, making DevOps accessible to everyone.

## ✨ Features

- **Ease of Use**: Simple commands to manage your deployment pipeline.
- **Automated Deployment**: Pushes code to Git, pushes to your server, builds Docker images, and runs containers automatically.
- **Remote Management**: Check status and stop applications directly from your terminal.
- **Secure Configuration**: Manages server credentials securely.
- **Docker Integration**: Automatically generates Dockerfiles if they don't exist.

## 🛠️ Installation

 Clone the repository and install the dependencies:

```bash
git clone <repository_url>
cd AUTO-FLOW
npm install
```

To use the `autoflow` command globally on your system, link the package:

```bash
npm link
```

## 🚀 Usage Guide

### 1. Global Setup
First, configure your global server details (like IP, username, and SSH key path). This only needs to be done once.

```bash
autoflow setup
```

### 2. Initialize a Project
Navigate to your project directory and initialize AutoFlow. This will create a configuration file (`autoflow.config.json`) and setting up Docker requirements.

```bash
autoflow init
```

### 3. Deploy
Deploy your application to the remote server with a single command. This handles Git syncing, SSH connections, folder setup, Docker building, and container execution.

```bash
autoflow deploy
```

### 4. Manage Application
Check if your application is running or stop it if needed.

```bash
# Check Status
autoflow status

# Stop Application
autoflow stop
```

## 📋 Command Reference

| Command | Description |
| :--- | :--- |
| `autoflow setup` | Configure global server details securely. |
| `autoflow init` | Initialize a new deployment configuration for the current project. |
| `autoflow deploy` | Deploy the current project to the remote server. |
| `autoflow status` | Check the status of the deployed application on the server. |
| `autoflow stop` | Stop the running application on the server. |

## ⚙️ Prerequisites

- **Local Machine**: Node.js installed, Git installed.
- **Remote Server**:
  - Docker installed and running.
  - SSH access enabled.
  - Git installed.

## 📂 Project Structure

- **`bin/index.js`**: CLI entry point.
- **`src/commands/`**: Implementation of all CLI commands (`init`, `deploy`, `setup`, `status`, `stop`).
- **`autoflow.config.json`**: Project-specific configuration (generated by `init`).
